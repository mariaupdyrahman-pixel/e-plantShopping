# e-plantShopping

## Paradise Nursery — Online Plant Shopping Application

Welcome to **Paradise Nursery**, an online plant shopping application built with React.

### Project Overview

Paradise Nursery allows users to explore a variety of houseplants and add their favorite plants to a shopping cart. The application is designed to provide a simple and user-friendly online shopping experience for plant lovers.

### Features

- Landing page with a link to browse plants.
- Navigation between the home page, product listing, and shopping cart.
- Plant product cards displaying images, names, descriptions, and prices.
- Plant categories, including aromatic and medicinal plants.
- Add-to-cart functionality.
- Shopping cart with quantity controls and the ability to remove items.
- Automatic calculation of item subtotals and the total cart cost.
- Continue Shopping and Checkout buttons.

### Technologies Used

- React
- JavaScript
- CSS
- Redux Toolkit

### Getting Started

1. Clone the repository.
2. Open the project folder.
3. Install the dependencies:

   ```bash
   npm install
   ```

4. Start the development server using the command supported by your project:

   ```bash
   npm run dev
   ```

   If your project uses Create React App, use `npm start` instead.

### Purpose

This project demonstrates React components, state management, Redux integration, dynamic rendering, and event handling in an online plant shop.
